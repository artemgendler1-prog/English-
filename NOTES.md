# Notes

Рабочий блокнот: предпочтения ученика и решения по методике.

## Ученик

- Артём. Родной язык — русский, объяснения на русском, весь материал — на английском.
- Время: 20–30 минут в день. Один урок = не больше 12–15 минут, остальное — повторение.
- Оборудование: наушники + микрофон. Аудиодиктанты и распознавание речи доступны.
- Самооценка на входе: «понимаю с субтитрами, без них теряюсь». Гипотеза — B1.
  Проверяется тестом `lessons/0001-placement-test.html`.
- Приоритет материала: американские фильмы и сериалы + живое общение (работа, поездки).

## Методические решения

- **Грамматику не преподаём отдельно.** Она появляется только там, где мешает понять
  услышанное (например, `would have` → `woulda`, `must have` → `musta`).
- **Приоритет тем по данным исследований**: reduction и assimilation ломают восприятие
  сильнее всего, linking легче. Значит редукции идут первыми, линкинг — после.
  Источник: [JETAL](https://jurnal.uhn.ac.id/index.php/jetal/article/view/2051).
- **Синтез речи (TTS) не редуцирует сам.** Если скормить ему `want to`, он произнесёт
  обе гласные. Поэтому в диктантах поле `say` содержит **редуцированную орфографию**
  (`whaddaya`, `musta`, `gonna`), а поле `expect` — нормальную. Ученик слышит редукцию и
  восстанавливает исходник. Это и есть тренируемый навык.
- **TTS — тренажёр, YouGlish — проверка.** В каждом уроке фразы линкуются на YouGlish,
  чтобы услышать их у настоящих носителей. Синтез не заменяет живую речь.
- Варианты ответа в квизах — одинаковой длины в словах, максимально близкие по символам,
  чтобы форма не подсказывала ответ.

## Технические ограничения (проверено)

- Уроки — обычные HTML-файлы, работают из `file://`. Скрипты подключаются классическим
  `<script src>`, **не** `type="module"` (модули блокируются CORS на `file://`).
- `SpeechRecognition` (распознавание речи) — только Chrome/Edge, требует интернета и
  иногда отказывается работать из `file://`. Поэтому рекомендуемый способ запуска —
  локальный сервер: `python3 -m http.server 8000`. Везде есть фолбэк на ввод текстом.
- `speechSynthesis` (озвучка) работает везде, включая `file://`.
- Прогресс живёт в `localStorage` браузера **и** выгружается в `progress/profile.json`
  через кнопку экспорта. Файл в репозитории — источник правды: только его я вижу между
  сессиями. Просить экспорт после каждого занятия.
