# Conversational English — курс Артёма

Приложение-тренажёр для разговорного английского на слух. Цель — смотреть американские
фильмы и сериалы без субтитров и свободно говорить с носителями. Подробно: [MISSION.md](MISSION.md).

## Продолжить занятия

Напиши в чате **«продолжи обучение»** — и всё. Клод сам поднимет
[progress/STATE.md](progress/STATE.md), увидит, чем закончилось прошлое занятие,
и продолжит с той же точки. Ничего вспоминать и объяснять заново не нужно.

Какой урок следующий и где он лежит — всегда в [progress/STATE.md](progress/STATE.md),
раздел «Следующий шаг». Здесь этот шаг не дублируется: два места про одно и то же
рано или поздно разойдутся, и ты пойдёшь по устаревшему.

После каждого урока нажимай **«Скопировать результат»** и вставляй в чат одним
сообщением. Это единственный способ передать прогресс: результат лежит в памяти
браузера, сам он ко мне не попадает.

## Как запустить

```bash
cd English-
python3 -m http.server 8000
```

Открой **<http://localhost:8000/app/index.html>** — это панель курса.

> Файлы можно открыть и двойным кликом (`file://`), озвучка будет работать.
> Но **распознавание речи** (проверка произношения) требует локального сервера — запускай
> через команду выше.

Нужен **Chrome** или **Edge**: только там есть и синтез речи, и распознавание.

## Как открыть с телефона

Локальный сервер на телефоне не поднять, поэтому урок собирается в один файл
и публикуется артефактом:

```bash
python3 tools/build-artifact.py lessons/0001-placement-test.html /tmp/lesson.html
```

Дальше файл публикуется как артефакт — открывается по ссылке в любом браузере.
Тест уровня уже опубликован: <https://claude.ai/code/artifact/c12c1fea-efb3-463c-ae8b-e063dcab6968>

Что теряется в этой сборке: задания на произношение (в Safari нет распознавания
речи) и кнопка «скачать файлом» (песочница артефакта блокирует загрузки).
Результат передаётся копированием — как обычно.

## С чего начать

1. Пройди [тест уровня](lessons/0001-placement-test.html) — 20 минут, наушники обязательны.
2. В конце нажми **«Скопировать результат»**.
3. Вставь скопированное в чат с Клодом в этой папке одним сообщением.
4. Я разберу ошибки и соберу следующий урок под них.

## Как это устроено

Приложение — это **тренажёр**, а Клод — **преподаватель**. Разделение простое:

| Делает браузер | Делает Клод |
| --- | --- |
| Озвучивает фразы, принимает ответы | Читает твои ошибки и находит в них систему |
| Мгновенно проверяет и объясняет | Пишет новые уроки под конкретные провалы |
| Хранит прогресс и очередь повторений | Решает, что учить дальше и когда усложнить |
| Считает уровень по CEFR | Отвечает на вопросы, разбирает фразы из фильмов |

Поэтому **прогресс нужно передавать после каждого занятия** — иначе я строю уроки вслепую.

## Структура

```
MISSION.md          зачем всё это — компас для каждого урока
GLOSSARY.md         термины курса (редукция, элизия, линкинг…)
RESOURCES.md        проверенные источники и сообщества
NOTES.md            предпочтения ученика и методические решения
CLAUDE.md           инструкция для преподавателя (для меня)

app/index.html      панель: уровень, слабые места, что повторять
lessons/*.html      уроки, по одному навыку на урок
reference/*.html    шпаргалки для быстрого возврата
assets/course.css   общий стиль курса
assets/engine.js    движок: озвучка, распознавание, прогресс, повторения
learning-records/   что уже освоено — растёт по мере занятий
progress/           profile.json — источник правды о твоём прогрессе
```

## Что говорить Клоду

Всё это рабочие запросы:

- «вот мой прогресс: `{...}` — сделай следующий урок»
- «продолжаем»
- «давай повторение»
- «услышал в сериале фразу *…* и не понял — разбери»
- «сделай урок только по `-a`-формам: `woulda`, `coulda`, `musta`»
- «слишком легко / слишком сложно»
