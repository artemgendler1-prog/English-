## Что было в прошлый раз

Ученик написал «продолжи уроки», **JSON по уроку 0002 не прислал**.
`progress/profile.json` до сих пор содержит только тест уровня от 2026-09-04.
Прошёл ли он урок 0002 — неизвестно.

Поэтому урок 0003 написан так, чтобы работать в обоих случаях: новый механизм плюс
три задания со старым `have` вперемешку и без анонса (`tags: ['mixed']`). Если 0002
не был пройден или не удержался, это будет видно по строке «Старое have вперемешку»
в отчёте.

**Урок 0003 «Куда девается you»** — ассимиляция `d/t` + `you`, 12 заданий:
<https://claude.ai/code/artifact/623e7f19-772c-4efd-bf53-c51bfd3dcc25>

Почему именно этот механизм: в тесте d6 (`Couldja gimme a hand with this for a sec?`)
дал 27% слов — худший результат из восьми диктантов. Ученик написал `cold … for a sec`:
искал в потоке отдельное `you`, которого физически нет — оно слилось с предыдущим
согласным в «дж». Туда же r3 (`whaddaya` → выбрал `what are you wanting`).

## Следующий шаг

**Ученик проходит урок 0003 и присылает JSON.**

Когда пришлёт:

1. Перезаписать `progress/profile.json` присланным целиком.
2. Смотреть три числа: общий результат, «Ассимиляция» и «Старое have вперемешку».
   - `mixed` провалено → механизм из 0002 не удержался, вернуть его третьим уроком
     на том же материале, а не двигаться дальше.
   - `assimilation` меньше половины → переписать 0003 с бо́льшим числом опор.
   - оба взяты (больше 9 из 12) → следующая тема **идиомы**: 0.2 из 1, единственный
     показатель ниже B1, и для сериалов они критичны.
3. Написать `lessons/0004-*.html`, добавить в массив `LESSONS` в `app/index.html`.
4. Собрать артефакт (`tools/build-artifact.py`), опубликовать, ссылку записать сюда.
5. Переписать этот файл.

**Если JSON снова не пришёл** — не выдавать четвёртый урок поверх двух непроверенных.
Собрать вместо этого короткий прогон-повторение из очереди `srs` по механизмам 0002+0003
и прямо сказать ученику: без экспорта прогресса я работаю вслепую.

## Что известно про ученика

- Занимается один, 20–30 минут в день.
- Работает **с телефона** (iOS). Локальный сервер поднять не может —
  каждый урок публиковать артефактом через `tools/build-artifact.py`.
- В Safari нет распознавания речи: задания типа `speak` там деградируют
  в ввод текстом. **Произношение до сих пор не измерено** — `intelligibility: 1`
  в профиле недостоверно, ученик вводил текст.
- Переслушивает по 8–12 раз без толку. Не предлагать «послушай ещё раз» как
  стратегию — давать опору для достраивания.
- В речи системно пропускает артикль `a` (`very cool film`, `stay hero`).
  Это тот же безударный /ə/, что и в `musta`. Связывать эти темы, а не разносить.
- Цель — американские сериалы без субтитров и разговор с носителями.
  Не экзамены, не письмо, не грамматика ради грамматики.
- Между занятиями бывает пауза в несколько дней. Уроки должны быть самодостаточными:
  повторять механизм предыдущего урока внутри следующего, а не ссылаться «как мы
  разбирали».

## Открытые вопросы

- Произношение — не измерено. Мерить, когда ученик доберётся до Chrome или Edge.
- Идиомы A1 при словаре B1 — разрыв не объяснён. Возможно, просто не сталкивался.
- Не подтверждено, проходит ли ученик выданные уроки вообще. Два урока выданы,
  ноль JSON получено. Если и после 0003 не будет экспорта — менять формат:
  делать уроки короче или встраивать отчёт прямо в чат.
